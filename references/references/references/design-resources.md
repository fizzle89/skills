# Design and vibe-coding resources (vetted 2026-10-02)

Free to use. Checked by loading each site on 2026-10-02. License notes come from the site text or the GitHub license file. "Check per item" means the license differs by component or asset, so read it before copying.

## Specs and prompt libraries
- https://designmd.ai - free DESIGN.md design systems for AI coding (DESIGN.md is an open format). Some items premium; use the free ones. Site text mentions CC0.
- https://styles.refero.design - website styles and DESIGN.md library. Free browsing; some paid tiers seen. Check per item.
- https://vibeprompts.dev - UI prompt library and Tailwind snippets. Has a pricing page; use the free ones only.

## Inspiration galleries (reference only, copy no assets)
- https://minimal.gallery, https://component.gallery, https://appshot.gallery, https://navbar.gallery, https://footer.design, https://cta.gallery, https://kage.design
- Use for layout and pattern reference. Some have paid templates; do not buy.

## Component libraries
- https://ui.shadcn.com - MIT (verified in repo). Base for Tenda and Pillar UI.
- https://ui.aceternity.com - free components plus a paid Pro tier. Use free only.
- https://magicui.design - free components plus paid templates. Use free only.
- https://motion-primitives.com - free, open source animated components.
- https://21st.dev - community components with an MCP server. License is per component. Check per item.
- https://uiverse.io - community CSS/Tailwind components. Blocked automated fetch (Cloudflare), so not verified. Check the license shown on each component.
- https://microkit.co - copy-paste React/CSS micro-interactions. Code is MIT per its FAQ. Some interactions are adapted from public examples; check per item.
- https://mapcn.dev - free, open-source map components for React.
- https://kinetics.colorion.co - spring-physics motion. MIT per site.
- https://text-effects.colorion.co - 99 CSS text effects, MIT per site.
- https://glass.samasante.com - liquid-glass effect. No license found; reference only until checked.
- https://animejs.com - Anime.js, MIT (verified in repo).

- https://beui.dev - free, open-source animated React/Next.js components (Motion). Has a Pro tier; use free only.
- https://evilcharts.com - free, open-source animated chart components for shadcn/ui (Recharts). License file is linked on the site (github.com/legions-developer/evilcharts). Use for Pillar dashboards.
- https://astryx.atmeta.com - Astryx design system, described on its site as open source and customizable. License file not checked; read it before copying.
- https://kobra.systems - component pages (free section plus a "Get Pro" tier). Use the Free section only; license not checked.
- https://beautifului.dev - "Beautiful UI" primitives for AI-native interfaces. Loads; license not found. Reference only.
- https://transitions.dev - UI transition patterns for AI agents. Has a Pro page; license not found. Reference only, free pages only.

## Assets
- https://kitbitz.art - 2,000+ free hand-drawn illustrations. Site says CC0.
- https://3dicons.co - open source and free 3D icons, plus a premium tier. Use only the free set and read its license page.

## Skipped
- scrolltide.co - the poster's own paid promo.
- reverseui.com - premium animated components, paid. Skipped.

## Rules for Pillar and Tenda pages
- Start from shadcn/ui, add motion from motion-primitives or Anime.js, and use a gallery for layout reference.
- Never ship a copied asset without checking its license. Never buy a Pro tier or a template.
- Every public page keeps the honest demo wording: early demo, sample data, simulated MoMo.
