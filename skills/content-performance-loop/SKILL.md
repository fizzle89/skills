# Content performance loop
Pattern from Easel's discover -> plan -> create -> publish -> attribute loop and Content-king style gates; own implementation, no auto-publishing.

1. **Log** each live post in /downloads/post-log.md: date, platform, URL, hook used, pillar, asset, format.
2. **Read results** (24h and 72h) from the platform's own surfaces we already hold: Buffer analytics, IG insights via Buffer, X/LinkedIn/YouTube notifications and Studio. No new logins, no new sessions. If a number is not visible, write "not visible", never estimate.
3. **Attribute:** compare to the account's own last 5 posts. Note hook pattern, format, time, reply quality (questions, saves, real comments) over raw likes.
4. **Lessons (max 3 per week):** each lesson = evidence + what to change. Add to the voice sheet or ideation scoring as a rule.
5. **Report only highlights** (a post that clearly beat or missed, a pattern across 3+ posts). Quiet weeks get no report.
6. Poll results (e.g. Tenda D3 A vs B) feed the next demo choice: the winning pain gets D4/D5 priority.
