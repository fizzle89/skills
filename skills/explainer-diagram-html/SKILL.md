# Explainer diagram + HTML page
1. Pick the diagram type: flow (steps), system map (parts and links), before/after, timeline, comparison table.
2. Real facts only: every box and number traces to a source or a live product screen. Mark demos as demos (Tenda: early demo, sample catalog, simulated MoMo).
3. Build one .html file: inline SVG, small CSS, minimal JS (click a step to reveal a plain-English note, toggle before/after). No external fonts or scripts. Works offline, mobile first.
4. Text in plain STE-style English, short labels, big type, high contrast, brand palette per pillar-design-pipeline.
5. Render in headless Chrome at phone and desktop width; inspect screenshots; check no clipped labels. Deliver the file as an attachment plus a PNG preview.
6. Reuse: the same diagram frames become carousel slides or video scenes (explainer-video-lab).
